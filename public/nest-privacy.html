Privacy Policy: "Home Assistant" (personal app)

Last updated: 2026-10-17

What this app is

"Home Assistant" is a private, single-household application. It lets the owner's own home-automation system (running on a computer in the owner's home) read the status of the owner's own Google Nest devices. It is not offered to the public and has no other users.

What data it uses

With the owner's permission through Google sign-in, the app can read device information from the owner's Google Nest account (for example temperature and device status). Nothing else from the Google account is requested.

How the data is used and stored

The data is used only inside the owner's home system, to show status to the owner and the owner's household. Sign-in tokens are stored only on that home computer. The data is not sold, not shared with third parties, not used for advertising, and not transferred anywhere outside the owner's home system.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Deleting access

The owner can revoke the app's access at any time in the Google Account security settings (Third-party access), and can delete the stored tokens from the home system.
