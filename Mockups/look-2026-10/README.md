# Look mock-ups, October 2026 (concept, not the finished game)

Three rounds of style tests made for Tom on 2026-10-28/29. Copied here from `.tmp/style-test*/`, which is not kept by git.

- `turning-town.html`, `two-cutaways.html`, `phone-panel.html`: one-file pages, open by double-click (they need internet only for the Poppins font).
- `lazy.html`, `cutaway.html`, `phones.html?v=a` or `?v=b`: the same pages as sources; they load `kit.js` (shared data, cutaway drawing, highlight wiring), `iso.js` (the model-town drawing kit) and `fonts/` (OpenDyslexic, OFL licence).
- `0-contact-sheet-round1/2/3.png`: one overview picture per round.
- `research-notes.md`: the web sources behind the choices (cutaways, highlight, dyslexia fonts, TV text sizes).
- `Unravel_Codes_style_ideas.pdf` (round 1), `Unravel_Codes_three_looks.pdf` (round 2): the PDFs Tom saw.

Tom's picks: the model town as a turning table (built as Round town in v3.9.8), officials talk in bubbles on the TV board, the phone keeps every number (phone version A), the flat cutaway first with a hidden drag to the angled one, Poppins + OpenDyslexic as a reader's choice.
