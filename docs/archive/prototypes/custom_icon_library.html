Why use these instead of emojis?

  • Thematic Consistency: They look like professional blueprint symbols rather than a mobile chat.
  • Color Scalability: We can dynamically change their color based on game state (e.g., turning a Work icon red if it's over budget).
  • Accessible: They render reliably on all OS versions (some Android versions have very different emojis than iOS).
